# 🔐 Cyber Intelligence Dashboard

## 📌 Overview

Cyber Intelligence Dashboard is a Python-based cybersecurity project that collects and displays publicly available technical information about a real website.

The user can enter any public domain, and the system verifies the domain through DNS before connecting to the website. It then collects real information from the website's public HTTP/HTTPS response and displays it in a colourful terminal dashboard.

## 🚀 Features

- Domain/DNS verification
- IP address lookup
- Website connectivity check
- HTTP status code
- Response time measurement
- HTTPS detection
- Final URL detection
- Redirect analysis
- Public server information
- Security header detection
- Public HTTP response headers
- Colourful terminal dashboard
- Works with different real public domains

## ⚙️ How It Works

```text
User enters a domain
        ↓
DNS verification
        ↓
IP address resolution
        ↓
Website connection
        ↓
HTTPS request
        ↓
Real website response
        ↓
Information extraction
        ↓
Cyber Intelligence Dashboard
